For people

Webmail and IMAP on the same mailbox

People get two ways in. Both are clients of the same API the agents use, so everyone sees one mailbox and one copy of each message.

Webmail, built in

Every Postern serves a webmail app at /webmail. It is one self-contained page with no build step. A new install turns on sign-in and creates your first admin login.

  • Inbox, Sent, Drafts, Archive, Junk and Trash folders, with threads.
  • Search in hybrid, full-text, semantic or literal mode, with filters.
  • Compose, reply, reply all and forward, when your login may send.
  • HTML email is shown in a sandboxed frame. No scripts run and no remote trackers load.
  • Light and dark themes, and a layout that works on a phone.

Screenshots use example data. Webmail setup and security model

IMAP for the mail app you already use

The IMAP proxy serves the Postern mailbox to Thunderbird, mutt, Apple Mail and iOS Mail. It reads mail, keeps the read and unread flag, and deletes when its token allows it. It is a small Python server, also built as a container image, that you run next to your Postern.
