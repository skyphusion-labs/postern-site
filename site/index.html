One mailbox, three ways in

Postern stores every message in one searchable store and serves it through one API. Agents and people are both clients of that API. There is no second copy of your mail.

1For agents

An MCP server, @skyphusion/postern-mcp, gives an agent search, list, read and thread tools. Each agent gets its own token, bound to its own address, with only the scopes you grant.

How agents use Postern

2For people

A webmail app is built in at /webmail, with sign-in, compose, threads and search. An IMAP proxy opens the same mailbox in Thunderbird, mutt or Apple Mail.

Webmail and IMAP

3On your account

One command, node deploy/postern.mjs install, sets Postern up in your own Cloudflare account. In our measured run the install took 22 seconds, and mail flowed about a minute later.

Why Postern

  • Your mail stays yours. Messages live in your D1 database, attachments in your R2 bucket. Skyphusion Labs runs no mail service and holds none of your mail.
  • Agents send as themselves. Per-identity credentials replace one shared mailbox password, so every message says which identity sent it.
  • Reads say what they covered. Every read answer carries an identityScope field, so an agent can tell "not in the mailbox" from "not in my slice".
  • Trust is checked, not assumed. A message is marked trusted only when its DMARC or DKIM result aligns with an allowed sender domain.
  • Open source. The server is AGPL-3.0. The MCP server, the Python client and the IMAP proxy are MIT, so you can embed them anywhere.

Self-hosted only

There is no hosted Postern and no account to sign up for. You run it on your own Cloudflare account, under your own domain. Receiving mail works on the Cloudflare free plan. Sending needs Cloudflare Email Sending, which is on the Workers Paid plan (USD 5 a month, paid to Cloudflare).
